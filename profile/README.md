# Flowery (플라워리)
## 프로젝트 개요
>  
## 프로젝트 소개
>플라워리는 하루의 작은 성취를 꽃으로 시각화함으로서 사용자들이 성취감과 동기부여를 경험할 수 있도록 합니다.

## 주요 기능
#### 1. To Do List
사용자가 오늘 달성해야할 목표를 작성할 수 있습니다.
#### 2. 화분
화분에서는 사용자가 To Do List의 달성횟수에 따라 씨앗을 기를 수 있습니다. 
계획 3개 이상 달성시 꽃이 핍니다.
#### 3. 화단
화단에서는 과거 기록을 살펴볼 수 있습니다. 과거의 화분들과 계획들을 확인해보세요.
#### 4. 친구
친구를 추가하여 메세지를 주고받을 수 있습니다. 친구의 접속 상태를 확인할 수 있습니다.
## 팀 구성
| 역할 | 담당자 | 설명 |
|---|---|---|
|Front-End|**표준성**, 배혜진, 신지수|UI 개발|
|Design| **이지우**|UI, 그래픽 디자인|
|Main server| **정현수**, 정인아, (김소민)|대부분의 비즈니스 로직 처리, 트래픽의 entrypoint 담당|
|Database| **임규민**, 강동훈, 박성빈|CQRS를 구현한 DB 서버|
|Auth Server| **양병현**, 김소민| 보안 관련 인증 서버|
|WebSocket Server| **이정**, 장태희|Real-Time Related Operations에 필요한 웹소켓 담당|
|Monitering| 임규민, 장태희| |
|Planning/PM| 허윤서| UI/UX 기획, PM 역할 수행|
